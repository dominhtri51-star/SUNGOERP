Nhập Số Dư Tồn Kho Đầu Kỳ Bằng Excel

Chuyển đổi danh sách hàng hóa có sẵn trong kho sang phần mềm mới nhanh chóng.

Quy Trình Chuyển Đổi Số Dư Đầu Kỳ:

  1. Tải file mẫu Excel chuẩn bên dưới về máy.
  2. Điền Mã SKU, Tên vật tư, ĐVT, Số lượng tồn thực tế trên kệ, Giá vốn và Vị trí kệ.
  3. Kéo thả hoặc tải file Excel đã điền lên hệ thống.
  4. Kiểm tra xem trước dữ liệu và bấm "Xác Nhận Nạp Vào Kho".

1. File Mẫu Excel Kiểm Kê Đầu Kỳ

Đã cấu hình sẵn các cột chuẩn: Mã SKU, Tên hàng, ĐVT, Kho, Kệ, Tồn thực tế, Giá vốn.

2. Chọn hoặc Kéo Thả File Excel Tồn Kho Vào Đây

Hỗ trợ định dạng .xlsx, .xls (Dung lượng tối đa 50MB)
